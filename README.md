# Cahier de français

A single-file French flashcard app. Open `index.html` in a browser.

- 7 decks (greetings, food, numbers, verbs, colours, days & months, around town), 70 cards with example sentences
- Flip FR→EN or EN→FR, hear pronunciation (browser speech)
- Type-the-answer mode: forgiving checker (ignores case, articles, missing accents with a note) plus an accent keyboard
- Streak counter with personal best
- Leitner-box spaced repetition; progress saved in localStorage
- Keys: Space flip, 1 again, 2 know, S speak
