# Cahier de français

A single-file French flashcard app. Open `index.html` in a browser.

- 5 decks (greetings, food, numbers, verbs, around town), 50 cards with example sentences
- Flip FR→EN or EN→FR, hear pronunciation (browser speech)
- Leitner-box spaced repetition; progress saved in localStorage
- Keys: Space flip, 1 again, 2 know, S speak
